# AllO2 AI 員工團隊

目標：讓讀者每週花 5 分鐘，就能掌握全球碳市場「變了什麼、為什麼重要、接下來要盯什麼」，
並且願意長期小額訂閱。

## 成員與狀態

| 角色 | 職責說明 | 狀態 |
|---|---|---|
| 撰稿員 | 現有 4 個排程任務（每日快訊、週一週報、週四掃描、週五文章） | 運作中 |
| 審稿員 | [審稿員.md](審稿員.md) | 已建立，待接上排程 |
| 研究員 | 收集消息與數字，給撰稿員用 | 規劃中 |
| 發佈員 | 執行 `tools/publish.py` | 規劃中（目前由撰稿員任務直接發佈） |
| 主管 | 每週營運報告：產出量、退回原因、網站成效 | 規劃中 |

所有人共用：[風格指南.md](風格指南.md)。

## 工作流程

```
撰稿員 ──寫入──▶ drafts/ ──審稿員──▶ approved/ ──發佈員──▶ tools/publish.py ──▶ afallo2.com
                     │
                     ├─▶ drafts/退回/    （撰稿員重寫）
                     └─▶ drafts/待確認/  （等你看）
```

`drafts/` 與 `approved/` 只放在執行排程的電腦上（已列入 `.gitignore`），
因為這時還沒經過禁止發佈清單的刪除，**絕不能推上 GitHub**。

## 接上審稿員（現有排程任務要改的地方）

把現有任務最後一步的

```bash
python tools/publish.py news 公開版.md
```

改成

```bash
cp 公開版.md drafts/
# 由審稿員任務依 team/審稿員.md 審稿，通過後才：
python tools/publish.py news approved/公開版.md
```
